財務回報簿 v5.2 PWA 測試版

1. 先在原記帳網頁下載 JSON 備份。
2. 將本資料夾的五個檔案上傳到原 GitHub Pages 網站同一層（替換 index.html）。不要只上傳 HTML。
3. 使用 Android Chrome 打開網站，從 Chrome 選單選「安裝應用程式」（不是單純新增捷徑）；如果已安裝舊版，可能需要移除舊捷徑重新安裝。
4. 在檔案管理員找到發票存摺匯出的 CSV，按分享，看看能否選擇「財務回報簿」。也可在網頁按選擇檔案。
5. 先用 10 月 CSV 選「只存歷史紀錄」，避免已結算的餘額再次扣款。

注意：資料仍存在本機瀏覽器 localStorage；若安裝版與 Chrome 分屬不同儲存環境，請使用 JSON 備份還原。CSV 不會被送至伺服器。Chrome 某些版本可能有分享檔案遺失問題，請改用網頁選檔案。
